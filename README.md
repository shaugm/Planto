# 🌱 Planto


**Planto** is a plant care reminder app built with SwiftUI. It helps users organize their plants, keep track of their daily watering progress, and receive reminders based on each plant's watering schedule.

## ✨ Main Features

- **Add Plants:** Add plants with their name, room location, light condition, watering frequency, and water amount.
- **Edit Plants:** Update the details of existing plants.
- **Delete Plants:** Remove plants and their associated watering reminders.
- **Watering Tracking:** Mark plants as watered and track daily progress.
- **Local Notifications:** Receive repeating watering reminders based on the selected watering frequency.
- **Daily Progress:** View how many plants have been watered throughout the day.
- **Completion Screen:** Display an "All Done!" screen when all plants have been watered.

## 🛠️ Technologies Used

- **Swift**
- **SwiftUI**
- **UserDefaults** – For local data persistence.
- **UserNotifications** – For scheduling local notifications.
- **MVVM Architecture** – To organize the app's code and separate UI from business logic.
- **Codable** – For encoding and decoding plant data.
